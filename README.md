# Git 그래프 패널

Claude 데스크톱 앱의 대화창 옆에서 Git 커밋 내역을 보는 모드입니다. VS Code 의 Git 그래프처럼 커밋을 훑고, 커밋을 눌러 변경 파일을 보고, 파일을 좌우로 비교할 수 있습니다.

## 기능

- **커밋 그래프**: 모든 브랜치의 최근 커밋 60개를 선과 점으로 표시
- **변경 파일 목록**: 커밋을 누르면 아래에 파일 이름, 폴더 경로, 상태(`M`·`A`·`D`)가 펼쳐짐
- **좌우 비교 탭**: 파일을 누르면 뒤에 탭이 열림. 파일마다 탭 하나이고, 같은 파일은 중복으로 열리지 않음
- **VS Code 식 비교 색**: 바뀐 줄과 바뀐 구간 강조, 코드 구문 색, 줄 번호
- **호버 표시**: 줄에 마우스를 올리면 회색으로 강조되고 앞의 점이 커짐
- **자동 갱신**: 30초마다 Git 내역을 다시 읽음

패널이 좁으면 비교 탭은 위아래 비교로 바뀌고, 브랜치·작성자 표시는 숨겨집니다.

## 설치

[INSTALL.md](INSTALL.md) 를 참고하세요. 앱에서는 입력창 옆 `+` → **Plugins** → **Add marketplace** 에 `92bulldozer/claude-git-graph` 를 입력한 뒤 `git-graph` 를 추가하면 됩니다.

## 사용법

Git 저장소 폴더로 새 세션을 열면 패널이 자동으로 뜹니다. 닫았다면 입력창에 `/git-graph` 를 입력합니다.

## 제한

- Claude 데스크톱 앱용입니다. Windows 에서 만들고 확인했습니다. 터미널에서는 커밋 목록만 글자로 보입니다.
- 앱이 커서 모양을 지정하는 기능을 열어 두지 않아 손 모양 커서가 나오지 않습니다.
- 앱이 패널 위치를 정하므로 대화창 오른쪽에만 열립니다.
- 패널 전체가 한 번에 스크롤되어, 목록과 비교 화면을 한 화면에 나란히 둘 수 없습니다. 비교는 탭으로 전환합니다.
- 색은 어두운 테마 기준입니다.
- 비교 탭은 파일당 약 9만 자, 800줄까지 표시합니다.

## 개인정보

Git 내역은 사용자 컴퓨터에서 읽어 패널에만 표시합니다. 이 모드는 커밋이나 코드를 외부로 보내지 않습니다.

## 개발

```bash
claude plugin validate .
claude plugin test .
```

`hooks/register.tsx` 가 패널 본체이고, `hooks/hit.tsx` 는 줄마다 겹치는 투명 클릭 영역입니다.
